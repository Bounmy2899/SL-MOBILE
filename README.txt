ໂພນມະນີ — ເວີຊັນເຊື່ອມ Supabase (ຖານຂໍ້ມູນຈິງ, ບໍ່ຕ້ອງຜູກບັດ)
====================================================================
คู่มือนี้เขียนเป็นภาษาไทย เพื่อให้ผู้เริ่มต้นทำตามได้ทีละขั้นตอน
(ตัวเว็บไซต์ที่ลูกค้าเห็นยังเป็นภาษาลาวเหมือนเดิมทุกอย่าง)


ทำไมเปลี่ยนจาก Firebase มาเป็น Supabase?
--------------------------------------------
Firebase เปลี่ยนนโยบายตั้งแต่ก.ย. 2024 ว่าการใช้ Storage (เก็บรูปภาพ) ต้อง
อัปเกรดเป็นแพ็กเกจ Blaze ซึ่งต้องผูกบัตรเครดิตก่อน (ถึงจะมี free tier
อยู่ในนั้นก็ตาม) ส่วน Supabase ให้ทั้งฐานข้อมูล (Postgres), ที่เก็บไฟล์
(Storage), และระบบล็อกอิน (Auth) ในแพ็กเกจฟรีโดยไม่ต้องผูกบัตรเลย
เหมาะกับร้านเล็กที่อยากเริ่มต้นแบบไม่มีความเสี่ยงเรื่องค่าใช้จ่าย


ก่อนอื่น: เปลี่ยนแปลงอะไรไปบ้าง?
---------------------------------
เดิมเว็บนี้เก็บสินค้า/ออเดอร์/รูปภาพทั้งหมดไว้ใน localStorage ของเบราว์เซอร์
เครื่องเดียว เวอร์ชันนี้เปลี่ยนไปใช้ Supabase แบ่งเป็น 3 ส่วนที่ใช้ในเว็บนี้:

  1. Database (Postgres) = ฐานข้อมูล เก็บสินค้า/หมวดหมู่/ออเดอร์/ค่าใช้จ่าย/
     ข้อมูลร้าน
  2. Storage              = ที่เก็บไฟล์ เก็บรูปสินค้า, รูป QR รับเงิน,
     ใบโอนเงิน, โลโก้
  3. Authentication        = ระบบล็อกอิน แทนรหัสผ่านที่ฝังไว้ในโค้ดแบบเดิม

ทุกคนที่เปิดเว็บนี้ (จากอุปกรณ์ไหนก็ตาม) จะเห็นข้อมูลชุดเดียวกัน แบบเรียลไทม์


ขั้นตอนที่ 1 — สร้างโปรเจกต์ Supabase
---------------------------------------
1. เข้า https://supabase.com/dashboard (สมัคร/ล็อกอินด้วย GitHub หรืออีเมล
   ก็ได้ — ไม่ต้องผูกบัตร)
2. กด "New project"
3. ตั้งชื่อโปรเจกต์ เช่น "phonemani-shop"
4. ตั้ง "Database Password" เก็บรหัสนี้ไว้ให้ดี (ใช้ต่อเมื่อจำเป็นเท่านั้น
   ไม่ใช่รหัสที่ใช้ล็อกอินเว็บ)
5. เลือก Region ที่ใกล้ที่สุด เช่น Singapore (ap-southeast-1)
6. กด "Create new project" รอสัก 1-2 นาทีจนโปรเจกต์พร้อมใช้งาน


ขั้นตอนที่ 2 — รันคำสั่งตั้งค่าฐานข้อมูล (ครั้งเดียว)
-----------------------------------------------------------
1. เมนูซ้ายมือ กด **SQL Editor**
2. กด **"New query"**
3. เปิดไฟล์ schema.sql ที่แนบมาให้ คัดลอกเนื้อหาทั้งหมด มาวางในช่องนี้
4. กด **"Run"** (หรือ Ctrl+Enter)
5. ถ้าเห็นข้อความ Success ก็เรียบร้อย — คำสั่งนี้จะสร้างตารางข้อมูลทั้งหมด,
   ตั้งกฎความปลอดภัย (RLS), เปิด Realtime, และสร้างที่เก็บรูปภาพให้พร้อมใช้
   ในครั้งเดียว

   *** ถ้าเจอ error บรรทัด "alter publication supabase_realtime add table..."
   ว่า "is already a member" ไม่ต้องตกใจ ข้ามได้เลย แปลว่าเปิดไว้แล้ว ***


ขั้นตอนที่ 3 — เปิดใช้งานระบบล็อกอิน (Authentication)
---------------------------------------------------------
1. เมนูซ้ายมือ กด **Authentication**
2. ไปแท็บ **Providers** เช็คว่า **Email** เปิดใช้งานอยู่ (ปกติเปิดมาให้แล้ว)
3. ไปแท็บ **Users** กด **"Add user"** → **"Create new user"**
4. ใส่อีเมล/รหัสผ่านจริงของผู้จัดการร้าน ติ๊ก **"Auto Confirm User"** ด้วย
   (ไม่งั้นต้องไปยืนยันอีเมลก่อนถึงจะล็อกอินได้)
5. กด Create user
   *** นี่คือบัญชีที่จะใช้กดปุ่ม "ຜູ້ຈັດການ" บนเว็บ แทน admin@phonemani.la เดิม ***


ขั้นตอนที่ 4 — เอาค่า Supabase มาใส่ในเว็บ
------------------------------------------------
1. เมนูซ้ายมือ กด ⚙️ **Project Settings** → **API**
2. คัดลอก **"Project URL"** (หน้าตาแบบ https://xxxxxxxx.supabase.co)
3. คัดลอก **"anon public"** key (อยู่ใต้หัวข้อ "Project API keys")
   *** อย่าคัดลอก "service_role" key มาใส่ในเว็บเด็ดขาด อันนั้นเป็นกุญแจลับ
   ที่ให้สิทธิ์เต็ม ถ้ารั่วไหลใครก็ลบข้อมูลร้านได้หมด ***
4. เปิดไฟล์ supabase-config.js (อยู่โฟลเดอร์เดียวกับ index.html) วางค่าทั้ง
   สองแทนที่ข้อความ "ໃສ່ຄ່າຂອງທ່ານ..."


ขั้นตอนที่ 5 — ทดสอบในเครื่องตัวเอง
---------------------------------------
*** ห้ามเปิดไฟล์ index.html แบบดับเบิลคลิกตรงๆ (file://) จะไม่ทำงาน ***
เพราะโค้ดใหม่ใช้ ES Modules ซึ่งต้องรันผ่านเว็บเซิร์ฟเวอร์ (http://) เท่านั้น

วิธีที่ง่ายที่สุดถ้ามี Node.js ในเครื่อง เปิด terminal ในโฟลเดอร์นี้แล้วพิมพ์:

    npx serve .

แล้วเปิดลิงก์ที่ขึ้นมา (เช่น http://localhost:3000) ในเบราว์เซอร์

หรือถ้าใช้ VS Code ติดตั้ง extension ชื่อ "Live Server" แล้วคลิกขวาที่
index.html เลือก "Open with Live Server"


ขั้นตอนที่ 6 — เอาเว็บขึ้นออนไลน์จริง (ฟรี ไม่ต้องผูกบัตร)
------------------------------------------------------------------
Supabase ไม่มี hosting ในตัว ต้องใช้บริการ static hosting แยกต่างหาก
วิธีที่ง่ายที่สุดสำหรับมือใหม่คือ **Netlify** (ลากไฟล์วาง ไม่ต้องติดตั้งอะไร):

  1. เข้า https://app.netlify.com/ สมัคร/ล็อกอินฟรี
  2. หน้า Dashboard จะมีกล่องเขียนว่า "Drag and drop your site output folder
     here" — ลากทั้งโฟลเดอร์เว็บนี้ (ที่มี index.html, app.js, style.css,
     supabase-config.js ที่แก้ค่าแล้ว) ไปวางตรงนั้น
  3. รอสักครู่ จะได้ลิงก์เว็บ เช่น https://phonemani-shop.netlify.app ใช้งาน
     ได้ทันที

ทางเลือกอื่นที่ฟรีเหมือนกัน: Vercel, Cloudflare Pages, GitHub Pages


ค่าใช้จ่าย
-----------
Supabase มีแพ็กเกจฟรี ("Free plan") ที่ให้ Database 500MB, Storage 1GB,
Auth ผู้ใช้ไม่จำกัดจำนวนที่ใช้งานจริง (MAU) 50,000 คน/เดือน เพียงพอสำหรับ
ร้านเล็ก-กลางสบายๆ โดยไม่ต้องผูกบัตรเลย (ต่างจาก Firebase ที่บังคับผูกบัตร
สำหรับ Storage) ถ้าร้านโตขึ้นมากค่อยดูเรื่องอัปเกรดเป็นแพ็กเกจ Pro
($25/เดือน) ทีหลังได้

*** ข้อควรรู้: โปรเจกต์ Free plan ของ Supabase จะถูกพักการทำงานอัตโนมัติ
(pause) ถ้าไม่มีการใช้งานติดต่อกัน 7 วัน — แค่เข้า dashboard แล้วกด
"Resume project" ก็กลับมาใช้ได้ปกติ ข้อมูลไม่หายแน่นอน (มีเวลาให้กู้คืนได้
นานถึง 1 ปีหลังพัก) เพียงแต่ต้องรู้ไว้เผื่อเปิดเว็บแล้วสินค้าไม่ขึ้นทันที
ต้องกลับไปกด Resume ก่อน ถ้าไม่อยากให้พักเลย ก็มีลูกเล่นเข้าเว็บ/เรียก API
สัปดาห์ละครั้งเพื่อกันไว้ หรืออัปเกรดเป็น Pro plan ทีหลังก็ได้ ***


เรื่องที่ควรรู้เพิ่มเติม
---------------------------
- ไฟล์ supabase-config.js มีค่า "anon public key" ค่านี้ "ไม่ใช่รหัสลับ"
  (Supabase ออกแบบมาให้ฝังในโค้ดฝั่งเว็บได้) ความปลอดภัยจริงๆ อยู่ที่ Row
  Level Security (RLS) policies ที่ตั้งไว้ในขั้นตอนที่ 2 ต่างหาก
- ถ้าลืมรหัสผ่านผู้จัดการ ไปที่ Supabase Dashboard > Authentication > Users
  กดที่ผู้ใช้คนนั้น แล้วรีเซ็ตรหัสผ่านได้จากตรงนั้น
- ต้องการเพิ่มผู้จัดการอีกคน ก็ไปเพิ่ม user ใหม่ในหน้าเดียวกันได้เลย ทุกคน
  ที่ล็อกอินได้ถือเป็นผู้จัดการเท่ากันหมด (เว็บนี้ยังไม่มีระดับสิทธิ์
  แยกย่อย — ถ้าต้องการ ค่อยพัฒนาเพิ่มทีหลังได้)
- ดูข้อมูลในตารางแบบตาราง Excel ได้ที่เมนู **Table Editor** ใน Supabase
  Dashboard สะดวกมากเวลาอยากเช็คข้อมูลตรงๆ โดยไม่ต้องเปิดเว็บ
