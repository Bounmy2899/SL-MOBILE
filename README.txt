ໂພນມະນີ — ເວີຊັນເຊື່ອມ Firebase (ຖານຂໍ້ມູນຈິງ)
=====================================================
คู่มือนี้เขียนเป็นภาษาไทย เพื่อให้ผู้เริ่มต้นทำตามได้ทีละขั้นตอน
(ตัวเว็บไซต์ที่ลูกค้าเห็นยังเป็นภาษาลาวเหมือนเดิมทุกอย่าง)


ก่อนอื่น: เปลี่ยนแปลงอะไรไปบ้าง?
---------------------------------
เดิมเว็บนี้เก็บสินค้า/ออเดอร์/รูปภาพทั้งหมดไว้ใน localStorage ของเบราว์เซอร์
เครื่องเดียว (เปิดจากมือถือลูกค้าจะไม่เห็นสินค้าที่ผู้จัดการเพิ่มจากคอมที่ร้าน)

เวอร์ชันนี้เปลี่ยนไปใช้ Firebase ซึ่งเป็นบริการฐานข้อมูลออนไลน์ฟรี (มี free
tier) ของ Google แบ่งเป็น 3 ส่วนที่ใช้ในเว็บนี้:

  1. Firestore   = ฐานข้อมูล เก็บสินค้า/หมวดหมู่/ออเดอร์/ค่าใช้จ่าย/ข้อมูลร้าน
  2. Storage      = ที่เก็บไฟล์ เก็บรูปสินค้า, รูป QR รับเงิน, ใบโอนเงิน, โลโก้
  3. Authentication = ระบบล็อกอิน แทนรหัสผ่านที่ฝังไว้ในโค้ดแบบเดิม

ทุกคนที่เปิดเว็บนี้ (จากอุปกรณ์ไหนก็ตาม) จะเห็นข้อมูลชุดเดียวกัน แบบเรียลไทม์
— ผู้จัดการเพิ่มสินค้าจากคอมที่ร้าน ลูกค้าเปิดจากมือถือจะเห็นทันที


ขั้นตอนที่ 1 — สร้างโปรเจกต์ Firebase
---------------------------------------
1. เข้า https://console.firebase.google.com/ (ล็อกอินด้วย Google account)
2. กด "Add project" / "สร้างโปรเจกต์" ตั้งชื่อ เช่น "phonemani-shop"
3. ขั้นตอน Google Analytics จะเปิดหรือปิดก็ได้ (ไม่จำเป็นสำหรับเว็บนี้)
4. กด Create project รอสักครู่จนเสร็จ


ขั้นตอนที่ 2 — เปิดใช้งาน Firestore Database
-----------------------------------------------
1. ในเมนูซ้าย เลือก Build > Firestore Database
2. กด "Create database"
3. เลือกโหมด "Start in production mode" (เราจะตั้งกฎเองในขั้นตอนที่ 6)
4. เลือก location/region ที่ใกล้ที่สุด เช่น asia-southeast1 (สิงคโปร์)
   *** เลือกครั้งเดียว เปลี่ยนภายหลังไม่ได้ ให้เลือกให้ดี ***


ขั้นตอนที่ 3 — เปิดใช้งาน Storage (ที่เก็บรูปภาพ)
----------------------------------------------------
1. ในเมนูซ้าย เลือก Build > Storage
2. กด "Get started" แล้วเลือก production mode เหมือนกัน
3. ใช้ location เดียวกับ Firestore ที่เลือกไว้


ขั้นตอนที่ 4 — เปิดใช้งานระบบล็อกอิน (Authentication)
---------------------------------------------------------
1. ในเมนูซ้าย เลือก Build > Authentication
2. กด "Get started"
3. ในแท็บ "Sign-in method" เลือก "Email/Password" แล้วเปิดใช้งาน (Enable) บันทึก
4. ไปแท็บ "Users" กด "Add user" ใส่อีเมล/รหัสผ่านจริงของผู้จัดการร้าน
   (นี่คือบัญชีที่จะใช้กดปุ่ม "ຜູ້ຈັດການ" บนเว็บ แทนที่ admin@phonemani.la เดิม)
   *** ใช้รหัสผ่านที่ปลอดภัยจริง อย่างน้อย 8 ตัวอักษร ***


ขั้นตอนที่ 5 — เอาค่า Firebase config มาใส่ในเว็บ
------------------------------------------------------
1. กด ⚙️ (รูปเฟือง) มุมซ้ายบน > Project settings
2. เลื่อนลงมาที่ "Your apps" กดไอคอน "</>" (Web) เพื่อเพิ่มแอปเว็บ
3. ตั้งชื่อแอป (ชื่ออะไรก็ได้ เช่น "phonemani-web") ไม่ต้องติ๊ก Firebase Hosting
   ก็ได้ กด Register app
4. ระบบจะโชว์โค้ด object ชื่อ firebaseConfig หน้าตาแบบนี้:

     const firebaseConfig = {
       apiKey: "AIzaSy...",
       authDomain: "phonemani-shop.firebaseapp.com",
       projectId: "phonemani-shop",
       storageBucket: "phonemani-shop.appspot.com",
       messagingSenderId: "123456789",
       appId: "1:123456789:web:abc123"
     };

5. คัดลอกค่าทั้งหมดนี้ไปวางแทนที่ในไฟล์ firebase-config.js (อยู่ในโฟลเดอร์
   เดียวกับ index.html) แทนที่ค่า "ໃສ່ຄ່າຂອງທ່ານ-..." ทุกบรรทัด


ขั้นตอนที่ 6 — ตั้งค่า Security Rules (สำคัญมาก ห้ามข้าม)
--------------------------------------------------------------
Security Rules คือกฎที่บอกว่า "ใครอ่าน/เขียนข้อมูลไหนได้บ้าง" ถ้าไม่ตั้ง
ใครก็เข้ามาแก้ไข/ลบข้อมูลร้านของท่านได้หมด

Firestore rules:
  1. ไปที่ Firestore Database > แท็บ "Rules"
  2. ลบข้อความเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ firestore.rules ที่แนบมาให้
  3. กด Publish

Storage rules:
  1. ไปที่ Storage > แท็บ "Rules"
  2. ลบข้อความเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ storage.rules ที่แนบมาให้
  3. กด Publish

กฎที่ตั้งให้นี้สรุปว่า: ลูกค้าดูสินค้า/สั่งซื้อ/อัปโหลดใบโอนได้โดยไม่ต้อง
ล็อกอิน แต่การเพิ่ม/แก้ไข/ลบสินค้า, เปลี่ยนสถานะออเดอร์, ตั้งค่า QR หรือ
โลโก้ ทำได้เฉพาะคนที่ล็อกอินเป็นผู้จัดการเท่านั้น


ขั้นตอนที่ 7 — ทดสอบในเครื่องตัวเอง
---------------------------------------
*** ห้ามเปิดไฟล์ index.html แบบดับเบิลคลิกตรงๆ (file://) จะไม่ทำงาน ***
เพราะโค้ดใหม่ใช้ ES Modules ซึ่งต้องรันผ่านเว็บเซิร์ฟเวอร์ (http://) เท่านั้น

วิธีที่ง่ายที่สุดถ้ามี Node.js ในเครื่อง เปิด terminal ในโฟลเดอร์นี้แล้วพิมพ์:

    npx serve .

แล้วเปิดลิงก์ที่ขึ้นมา (เช่น http://localhost:3000) ในเบราว์เซอร์

หรือถ้าใช้ VS Code ติดตั้ง extension ชื่อ "Live Server" แล้วคลิกขวาที่
index.html เลือก "Open with Live Server"


ขั้นตอนที่ 8 — เอาเว็บขึ้นออนไลน์จริง
------------------------------------------
วิธีง่ายที่สุด (แนะนำ) คือ Firebase Hosting เพราะอยู่ระบบเดียวกับฐานข้อมูล
เลย ฟรี และมี HTTPS ให้พร้อม:

  1. ติดตั้ง Firebase CLI (ครั้งเดียว):   npm install -g firebase-tools
  2. ล็อกอิน:                              firebase login
  3. ในโฟลเดอร์เว็บนี้ พิมพ์:              firebase init hosting
     - เลือก "Use an existing project" แล้วเลือกโปรเจกต์ที่สร้างไว้
     - public directory ตอบว่า "." (โฟลเดอร์ปัจจุบัน)
     - Configure as single-page app? ตอบ No
     - อย่าให้มันเขียนทับ index.html ที่มีอยู่ (ตอบ No ถ้าถาม overwrite)
  4. อัปโหลดขึ้นเว็บ:                       firebase deploy

เสร็จแล้วจะได้ลิงก์ เช่น https://phonemani-shop.web.app ใช้ลิงก์นี้เปิดร้าน
ให้ลูกค้าได้เลย (ไม่ต้องมีโฮสติ้งอื่นอีก)


ค่าใช้จ่าย
-----------
Firebase มีแพ็กเกจฟรีชื่อ "Spark plan" ซึ่งเพียงพอสำหรับร้านเล็ก-กลาง
(Firestore ~50,000 อ่าน/20,000 เขียนต่อวันฟรี, Storage 5GB ฟรี, Hosting
10GB/เดือนฟรี) ถ้าร้านโตขึ้นมากค่อยดูเรื่องอัปเกรดเป็น Blaze plan
(จ่ายตามการใช้งานจริง) ทีหลังได้


เรื่องที่ควรรู้เพิ่มเติม
---------------------------
- ไฟล์ firebase-config.js มีค่า apiKey ของโปรเจกต์ ค่านี้ "ไม่ใช่รหัสลับ"
  (Google ออกแบบมาให้ฝังในโค้ดฝั่งเว็บได้) ความปลอดภัยจริงๆ อยู่ที่ Security
  Rules ในขั้นตอนที่ 6 ต่างหาก อย่างไรก็ตามไม่ควรแชร์ไฟล์นี้ต่อสาธารณะเกิน
  ความจำเป็น
- ถ้าลืมรหัสผ่านผู้จัดการ ไปที่ Firebase Console > Authentication > Users
  แล้วรีเซ็ตรหัสผ่านได้จากตรงนั้น
- ต้องการเพิ่มผู้จัดการอีกคน ก็ไปเพิ่ม user ใหม่ในหน้าเดียวกันได้เลย ทุกคน
  ที่ล็อกอินได้ถือเป็นผู้จัดการเท่ากันหมด (เว็บนี้ยังไม่มีระดับสิทธิ์
  แยกย่อย เช่น ผู้ช่วยที่ดูออเดอร์ได้อย่างเดียว — ถ้าต้องการ ค่อยพัฒนาเพิ่ม
  ทีหลังได้)
